# REEF RUN: Kickstarter campaign package

Individual Dutch project, EUR. **v2 (2026-10-20): goal €14,000 (or lean €6,000), tiers €5–€199**, rebuilt from the Full Charge playbook and 18 successful comparables (14).

Start with **`12_LAUNCH_READINESS_AUDIT.md`** (the verdict), then **`NEXT_ACTIONS.md`** (what's needed from you).

| File | What it is |
|---|---|
| `00_GAME_AUDIT.md` | What the game is and isn't today, with evidence |
| `01_MARKET_RESEARCH.md` | Comparables, Kickstarter rules and data, positioning |
| `02_DEMAND_VALIDATION.md` | A 12-week plan to prove demand before any campaign, plus go/no-go gates |
| `03_BUDGET_AND_FUNDING.md` + `03_funding_model.xlsx` | Budget, goal, fees, sensitivity (editable) |
| `04_CAMPAIGN_COPY.md` | Page copy (draft, AI-assisted; disclose or rewrite) |
| `05_REWARD_TIERS.md` | 7 digital tiers, costs, paste-ready text |
| `06_VISUAL_ASSET_PLAN.md` | Specs, art direction, produced graphics, capture list |
| `07_CAMPAIGN_VIDEO.md` | Script, storyboard, capture and edit instructions (animatic in `assets/video`) |
| `08_MARKETING_PLAN.md` | Pre-launch to post-campaign plan |
| `09_SOCIAL_CONTENT_CALENDAR.md` | 32 short-form concepts and a dated calendar |
| `10_OUTREACH_TEMPLATES.md` | Community, email, update, creator and press templates |
| `11_CAMPAIGN_DASHBOARD.md` + `11_campaign_dashboard.xlsx` | Live tracking, forecasts, triggers, contingency plans |
| `12_LAUNCH_READINESS_AUDIT.md` | Weighted scorecard and blockers |
| `13_KICKSTARTER_DRAFT_FIELDS.md` | What to type into each tab of Kickstarter's project editor |
| `14_WHAT_SUCCESSFUL_CAMPAIGNS_DO.md` | 12-month dataset (1,361 campaigns), KickTraq curves, 18 teardowns, budgets, gap analysis |
| `15_CAMPAIGN_COPY_V2.md` | Page v2 in the guide's order (replaces 04) |
| `16_TOOLS_PRESS_KIT_EMAIL.md` | Press kit (IMPRESS), email sequence (Brevo/EmailOctopus), Linktree, Canva kit, GIF recipe (EzGif/ffmpeg), listings |
| `KICKSTARTER_COPY_SHEET.html` | The same, as a page with a Copy button per field (open it in Chrome) |
| `PROJECT_STATE.md` / `NEXT_ACTIONS.md` | Status and your to-do list |
| `research/` | Source log and raw data |
| `assets/` | Graphics, social, landing page, video animatics, trackers, asset register |
| `tools/` | Scripts that rebuild every generated file |
